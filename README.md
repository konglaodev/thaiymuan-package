# ແພ໊ກເກັດຖ່າຍຮູບງານດອງ — Wedding Price List

ໜ້າເວັບສະແດງລາຄາແພ໊ກເກັດຖ່າຍຮູບ ແລະ ຖ່າຍວິດີໂອງານດອງ (ໄຟລ໌ດຽວ `index.html`, ບໍ່ຕ້ອງ build).

## ເປີດເບິ່ງຢູ່ເຄື່ອງ
ເປີດ `index.html` ດ້ວຍ browser ໂດຍກົງ.

## ຂຶ້ນ GitHub Pages
1. Push repo ນີ້ຂຶ້ນ GitHub
2. Settings → Pages → Source: **Deploy from a branch**
3. Branch: `main`, Folder: `/ (root)` → Save
4. ປະມານ 1 ນາທີ ເວັບຈະຢູ່ `https://<username>.github.io/<repo>/`

## ແກ້ໄຂ
- ລາຄາ / ລາຍລະອຽດ: ແກ້ໃນ `index.html` ແຕ່ລະ `<article class="card">`
- ເບີໂທ ແລະ ຊ່ອງທາງຕິດຕໍ່: ແກ້ຢູ່ `<footer>`
- ສີ ແລະ ຟອນ: ແກ້ຢູ່ `:root` ດ້ານເທິງຂອງ `<style>`
